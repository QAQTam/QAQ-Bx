# Roadmap v0.5.0 → v0.10.0

> 节奏:约 4 小时 / 版本。每版 = 1 个主题 + 1 个稳定性项,做不完的砍到下一版,不拖版本。
> 每版固定收尾(约 40 min):单测 → selftest 新场景 → ui-edge 自动化点击 → `Update-X.Y.Z.md` → `just dev` 出包 → 删令牌。

## 总览

| 版本 | 主题 | 一句话卖点 | 需登录 |
|---|---|---|---|
| 0.5.0 | 我的 B 站(上) | 历史 / 稍后再看 + 断点续播 | ✅ |
| 0.6.0 | 我的 B 站(下) | 关注动态 / 收藏夹 + 三连 | ✅ |
| 0.7.0 | 看得更舒服 | 字幕 + 弹幕屏蔽 + 跳过恰饭 | 部分 |

## 风险与预案

- **风控(-352 / wbi 签名)**:每个新端点先在 openapi 夹具录制,接口失败统一降级空态 + 日志,不 panic。
- **登录依赖**:0.5 / 0.6 / 0.9 开工前需用户登录一次;测完删令牌副本。
- **超时**:每版只保"主题第一项",其余可顺延;0.10 不加新功能以外的东西。
